## Project Overview
The application will be an Online Restaurant Ordering System (OROS) that allows users to place orders from the 
restaurant and staff to update, adjust, and finalize customer orders. The goal, according to the stakeholders, is to 
“provide my customers with a seamless online ordering experience to increase sales and enhance customer satisfaction.” 
The benefits of this application is to create a smooth ordering process for both users and staff, while monitoring 
restaurant inventory and ensuring up to date information on both ends. Users will be able to create an account, add 
preferences, rate their orders, and utilize promotional codes/discounts. On the staff side, users will be able to easily 
update menu items, create promotional codes, and gather data from past orders, reviews, and more.

## Features
1. Menu browsing
2. Order placement & tracking
3. Guest checkout option
4. Payment processing
5. Promotional codes/discounts
6. Customer feedback 
7. Data analysis/reporting
8. System documentation
